Bank Simulator

شبیه‌ساز درگاه SEP سامان برای QA و توسعه — بدون اتصال به بانک واقعی.

این سرویس فقط برای تست است. پول واقعی جابه‌جا نمی‌شود و نباید در پروداکشن استفاده شود. دادهٔ Redis رایگان ممکن است بعد از ری‌استارت پاک شود؛ اولین درخواست بعد از بیکاری ممکن است چند ده ثانیه طول بکشد (cold start).

شروع سریع

  1. یک merchant بسازید
  2. با TerminalId توکن پرداخت بگیرید
  3. صفحهٔ پرداخت را باز کنید و Pay / Cancel بزنید
  4. تراکنش را Verify کنید

۱) ثبت merchant

curl -s -X POST {{.BaseURL}}/merchants/register \
  -H 'Content-Type: application/json' \
  -d '{"name":"Demo Shop"}'

۲) درخواست توکن

curl -s -X POST {{.BaseURL}}/saman/sep.shaparak.ir/onlinepg/onlinepg \
  -H 'Content-Type: application/json' \
  -d '{
  "action": "token",
  "TerminalId": "YOUR_TERMINAL_ID",
  "Amount": 100000,
  "ResNum": "ORDER-1001",
  "RedirectUrl": "https://example.com/callback"
}'

۳) صفحهٔ پرداخت

{{.BaseURL}}/saman/sep.shaparak.ir/OnlinePG/SendToken?token=YOUR_TOKEN

Endpointهای مفید

  • GET /health
  • POST /merchants/register
  • POST /saman/sep.shaparak.ir/onlinepg/onlinepg
  • GET /saman/sep.shaparak.ir/OnlinePG/SendToken
  • POST /saman/sep.shaparak.ir/verifyTxnRandomSessionkey/ipg/VerifyTransaction
